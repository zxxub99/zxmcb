# 钟祥莫愁帮 - Cloudflare Pages 部署（图解版）

## 步骤总览

```
1. 登录 Cloudflare      → https://dash.cloudflare.com
2. 点击 Workers & Pages  → 顶部导航栏
3. 点击 Create application → 进入创建页面
4. 选择 Pages 标签       → 在顶部标签栏
5. 点击 Create a project → 蓝色大按钮
6. 连接 GitHub          → 选择仓库
7. 配置构建             → 填写设置
8. 部署完成             → 访问网站
```

---

| 设置项 | 值 | 复制 |
|--------|-----|------|
| Project name | `zxmcb` | ✅ |
| Production branch | `main` | ✅ |
| Build command | `cd frontend && npm install && npm run build` | ✅ |
| Build output directory | `frontend/dist` | ✅ |

## 故障排查

### 问题：没有看到 Pages 标签？
**解决：** 在顶部导航栏仔细找，"Workers" 和 "Pages" 是并排的标签

### 问题：没有 Create application 按钮？
**解决：** 刷新页面，或清除浏览器缓存后重试

### 问题：构建失败？
**解决：** 检查 Build command 和 Build output directory 是否正确填写
